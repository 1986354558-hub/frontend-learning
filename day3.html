第 3 天：CSS Flexbox —— 轻松排版

一、默认横向排列

给容器加上 display: flex，子元素自动排成一行。

.flex-row { display: flex; gap: 12px; }
▼ 效果
A
B
C

二、水平+垂直居中（最常用！）

justify-content: center 控制水平方向；align-items: center 控制垂直方向。

.flex-center { display: flex; justify-content: center; /* 水平居中 */ align-items: center; /* 垂直居中 */ height: 120px; }
▼ 效果
我在正中央

三、两端对齐

justify-content: space-between 让子元素贴住两端，中间均匀散布。

.flex-between { display: flex; justify-content: space-between; }
▼ 效果

四、自动换行

flex-wrap: wrap 让子元素在空间不够时自动换到下一行。

▼ 效果（缩小浏览器窗口看看）
卡片1
卡片2
卡片3
卡片4
卡片5
