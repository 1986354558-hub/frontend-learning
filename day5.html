第 5 天：DOM 操作 —— JS 操控网页

一、找到页面上的元素

要操控某个元素，首先得"找到"它。

// 方法1：通过 id 找（id 在整个页面唯一） var title = document.getElementById("mainTitle"); // 方法2：通过 CSS 选择器找（更灵活，和 CSS 写法一样） var box = document.querySelector(".target-text"); // 找 class="target-text" var btn = document.querySelector("#myBtn"); // 找 id="myBtn"

二、修改文字和样式

var el = document.getElementById("mainTitle"); el.textContent = "新标题"; // 改文字内容 el.style.color = "red"; // 改文字颜色 el.style.fontSize = "28px"; // 改字号（CSS 里是 font-size，JS 里写成 fontSize） el.style.backgroundColor = "#eee"; // 改背景色

三、创建和添加新元素

var newP = document.createElement("p"); // 创建一个

标签 newP.textContent = "我是新添加的段落！"; // 给它写上文字 document.body.appendChild(newP); // 把新段落加到页面末尾
