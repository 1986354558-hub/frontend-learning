第 4 天：JavaScript 基础 —— 变量与函数

一、JavaScript 写在哪里？

写在 HTML 的 <script></script> 标签里，通常放在 </body> 之前。

二、变量：存放数据的盒子

let 声明可改变的变量；const 声明不可改的常量。

let name = "小明"; // 声明变量 name，放入字符串 "小明" const age = 18; // 声明常量 age，放入数字 18（不可改） let score = 95; // 数字类型 let isPass = true; // 布尔类型：true 或 false console.log(name); // 在控制台打印（按 F12 可看到）

三、函数：封装代码，反复使用

function sayHello(userName) { // 定义函数，userName 是参数 return "你好，" + userName + "！"; // return 把结果返回 } let result = sayHello("小明"); // 调用函数，传入参数

四、模板字符串

用反引号 ` ` 包住文字，${变量} 插入变量，比用 + 号拼接直观。

let price = 99; let msg = `价格是 ${price} 元`; // 等于 "价格是 99 元"
