7天前端入门

每天一个知识点，每个知识点一个可运行的小案例。所有代码都附有逐行中文注释。

  • 第 1 天
    HTML 标签 —— 网页的骨架
    认识 <html>、<h1>、<p>、<img>、<a> 等基础标签，搭出第一个网页。
  • 第 2 天
    CSS 样式 —— 给网页穿上衣服
    颜色、字体、背景、边距、边框……学会用 CSS 把网页变好看。
  • 第 3 天
    CSS Flexbox —— 轻松排版
    用 display: flex 让元素自动对齐、居中、换行，告别混乱布局。
  • 第 4 天
    JavaScript 基础 —— 变量与函数
    let、const、字符串、数字、函数……认识网页的"大脑"。
  • 第 5 天
    DOM 操作 —— JS 操控网页
    用 JavaScript 找到网页元素，改文字、换颜色、增减内容。
  • 第 6 天
    事件处理 —— 让网页"活"起来
    点击按钮、输入文字、提交表单——学会响应用户的每一个操作。
  • 第 7 天
    综合实战 —— 待办事项小工具
    综合前 6 天的知识，从零做一个能增删改查的 Todo List。
使用方式每天打开对应的 HTML 文件（双击即可在浏览器打开），页面上半部分是带注释的代码讲解，下半部分是运行效果。边看边改、边改边刷新，这是学前端最快的方式。
