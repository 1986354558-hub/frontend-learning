第一部分：CSS 选择器

一句话解释：选择器就是告诉浏览器"我要给哪些元素加样式"。选得准不准，全靠选择器。

1. 基础选择器 — 三种最常见的"点名"方式

大白话： 元素选择器 = 喊"所有姓张的站出来"（按标签名）；
类选择器 = 喊"戴红帽子的举手"（按 class，可多人共享）；
ID 选择器 = 喊"工号 007 出列"（按 id，整个页面唯一）。
/* 元素选择器：选所有 <p> */ p { color: blue; } /* 类选择器：选所有 class="card" */ .card { border-radius: 10px; } /* ID 选择器：选 id="title"（只有那一个） */ #title { font-size: 24px; }

2. 组合选择器 — 按"关系"找人

大白话： 后代（空格）= "你部门所有人（不管几级下属）"；
子代（>）= "只算你的直属下级"；
相邻兄弟（+）= "紧挨着你的下一个同事"；
通用兄弟（~）= "你后面所有同级同事"。
/* 后代：div 里面所有 span（不管隔几层） */ div span { color: red; } /* 子代：div 直属儿子 span */ div > span { color: green; } /* 紧挨着的下一个兄弟 */ h2 + p { font-weight: bold; }
外层 div 直属 span →
  内层 div 孙子 span →

后代选择器会同时命中"直属 span"和"孙子 span"；子代选择器只命中"直属 span"

3. 属性选择器 — 按"特征"筛选

大白话：就像你说"把戴眼镜的人叫出来"（有某属性）、"把穿红色衣服的找出来"（属性等于某值）。 特别适合给不同类型的 input 加样式。
/* 有 placeholder 属性的 input */ input[placeholder] { border-color: blue; } /* type="email" 的 input */ input[type="email"] { background: #fff0f3; }

input[placeholder] 命中第 1、2、4 个；input[type="email"] 只命中第 2 个

4. 伪类选择器 — 按"状态"或"位置"选

大白话：伪类不是写死在 HTML 里的 class，而是浏览器根据状态（鼠标悬停、是否第一个、第几个）动态算出来的。
/* 鼠标悬停 */ li:hover { background: pink; } /* 第一个子元素 */ li:first-child { color: red; } /* 奇数行（隔行变色） */ li:nth-child(odd) { background: #f5f5f5; }

5. 伪元素 — 凭空"造"出内容

大白话：伪元素可以在不写 HTML 的情况下，用 CSS 在元素前后"插"东西。 ::before 插在前面，::after 插在后面。必须配合 content 属性使用。 常用于加装饰图标、清除浮动、自定义列表符号等。

6. 选择器优先级（权重）— 谁说了算？

大白话：同一个元素被多个选择器"抢"，浏览器按一套记分规则来决定。
记分方式：(ID数量, 类/属性/伪类数量, 元素/伪元素数量) → 像三位的数字
口诀：ID 权重最高，类其次，标签最低。行内样式 > ID > 类 > 标签。!important 是核武器，慎用。
选择器权重 (ID, 类, 元素)比喻
* (通配符)(0,0,0)小透明
div(0,0,1)普通士兵
.box(0,1,0)排长
div.box(0,1,1)排长 + 士兵
#app(1,0,0)将军
style="..." 行内(1,0,0,0)元帅，压一切

第二部分：Flex 布局

一句话解释：Flex 就是让一堆元素在一行（或一列）里自动排好，对齐、间距、换行全部交给 CSS 处理，不需要手动算位置。

1. 核心概念：容器 vs 项目

大白话：给父元素加上 display: flex，它就变成了一个"弹性容器"。 里面的直接子元素自动变成"弹性项目"，开始在容器里按规则排列。
关键：flex 只管理直接儿子，不管孙子。
/* 父元素加上这一行，子元素就自动排成一行 */ .container { display: flex; }

外层红框 = flex 容器；每个蓝/绿/紫块 = flex 项目。容器和项目各有自己的一套属性。

2. 主轴和交叉轴 — 理解 flex 的关键

大白话：flex 布局有两条轴线——主轴（项目排列的方向）和交叉轴（垂直于主轴）。
默认主轴是水平从左到右，所以项目默认排成一行。
justify-content 管主轴方向的对齐，align-items 管交叉轴方向的对齐。

3. flex-direction — 主轴方向

大白话：决定项目从左到右排、从右到左排、从上到下排、还是从下到上排。
改了方向后，主轴和交叉轴也会跟着转。

6. flex-wrap（换行）和 gap（间距）

大白话：默认 flex 不换行，所有项目挤在一行。加上 flex-wrap: wrap 后，放不下就自动换行。
gap 就是项目之间的间距，不用再写麻烦的 margin 了。

7. 项目属性：flex-grow / flex-shrink / flex-basis

大白话： flex-grow = "有多贪"（剩余空间按比例瓜分，默认 0 不抢）；
flex-shrink = "有多能忍"（空间不够时按比例缩，默认 1）；
flex-basis = "初始大小"（项目起步多宽/多高，默认 auto）。
常用简写：flex: 1 = flex-grow:1; flex-shrink:1; flex-basis:0（均分空间）。
flex: 1

点按钮后三个项目按 1:2:1 分宽度——中间那个是两倍宽

8. align-self 和 order — 单个项目"搞特殊"

大白话： align-self 让某个项目不跟大伙对齐，自己单独决定在交叉轴上的位置；
order 改项目的排列顺序（数字越小越靠前，默认 0），HTML 顺序不变，视觉顺序变了。
order: 3
order:1 + 顶部
order:2 + 底部

虽然 HTML 里写成 1-2-3 的顺序，但视觉上被 order 重排成了 中间-右边-左边。
红色两个分别用 align-self 把自己钉在顶部和底部。
