第 2 天：CSS 样式 —— 给网页穿上衣服

一、CSS 写在哪里？

CSS 可以写在 HTML 的 <style> 标签里（本页所有案例都是这样），也可以写在单独的 .css 文件里再引入。

二、选择器：你想给谁加样式？

选中 HTML 标签有三种常用方式：

/* 方法1：标签选择器 —— 选中所有同名标签 */ h1 { color: red; } /* 方法2：类选择器 —— 选中所有 class="xxx" 的元素（最常用！）*/ .highlight { background-color: yellow; } /* 方法3：id 选择器 —— 选中唯一 id="xxx" 的元素 */ #special { font-size: 20px; }

三、颜色：color 和 background-color

.red-text { color: red; } /* 文字变红 */ .blue-bg { background-color: #4a90d9; } /* 背景变蓝（用十六进制）*/

四、盒子模型：margin、padding、border

每个 HTML 元素都可以看作一个"盒子"，从外到内依次是：
margin（外边距） → border（边框） → padding（内边距） → content（内容）

.box-demo { width: 200px; /* 内容区宽 */ height: 60px; /* 内容区高 */ padding: 20px; /* 内边距：文字和边框之间留白 */ border: 3px solid #4a90d9; /* 边框：粗细 3px，实线，蓝色 */ margin: 24px auto; /* 外边距：上下 24px，左右自动(居中) */ border-radius: 8px; /* 圆角 8px */ }
